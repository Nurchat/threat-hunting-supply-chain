# Threat Intelligence & Integrity Verification in Software Supply Chains

**Course:** Introduction to Threat Hunting (2026–2027)  
**Student:** Nurkhat Zholseiit (Individual Research Track)  
**Topic:** Threat Intelligence, OSINT Reconnaissance, and Data Integrity Verification for Software Supply Chain Security

## Project Scope
This project investigates software supply chain compromises, focusing on dependency confusion, poisoned open-source packages, and integrity verification of distributed software artifacts.

## Increments & Deliverables
- `docs/week1_glossary.md`: CTI glossary and ENISA-aligned threat taxonomy for software supply chains.
- `docs/week2_osint.md`: OSINT reconnaissance queries (Shodan, VirusTotal, Maltego) and data source mapping matrix.
- `docs/week3_misp.md`: MISP environment deployment specification and automated IOC verification pipeline.
- `scripts/verify_artifacts.py`: Lightweight Python integrity validation pipeline (SHA-256 / Merkle verification prototype).
